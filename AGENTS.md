\# StudySense AI Instructions



Build a lightweight student machine-learning portfolio project.



The project must run on an Intel Celeron laptop with 8 GB RAM.



Use Python, pandas, scikit-learn, joblib, matplotlib, seaborn, Streamlit, and pytest.



Do not use deep learning, large language models, GPU requirements, huge datasets, or external APIs.



Keep the code beginner-friendly and organized.



The project should:

\- Load and validate a small educational dataset.

\- Train lightweight regression and classification models.

\- Evaluate models honestly.

\- Save trained models with joblib.

\- Provide a Streamlit dashboard.

\- Include automated tests.

\- Include a complete README.



Do not invent metrics, test results, or observations.



Before changing files:

1\. Inspect the current project.

2\. Explain the planned changes.

3\. Make only the requested phase.

4\. Run relevant tests.

5\. Report exactly what passed and failed.



This is an educational project, not an official academic assessment system.

Do not claim that predictions are perfectly accurate.

Do not claim that feature importance proves causation.

Clearly explain limitations.
